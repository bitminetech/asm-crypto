# X25519

## Contents

### Functions

- [`crypto_x25519`](#function-crypto_x25519): computes X25519 of a scalar and a u-coordinate.
- [`crypto_x25519_invert`](#function-crypto_x25519_invert): computes 1 / a mod p.
- [`crypto_x25519_mul`](#function-crypto_x25519_mul): multiplies two field elements.
- [`crypto_x25519_mul_a24`](#function-crypto_x25519_mul_a24): multiplies a field element by 121665.
- [`crypto_x25519_add`](#function-crypto_x25519_add): adds two field elements.
- [`crypto_x25519_sub`](#function-crypto_x25519_sub): subtracts two field elements.
- [`crypto_x25519_cswap`](#function-crypto_x25519_cswap): swaps two field elements under a mask.

### Types

- [`X25519Bytes`](#type-x25519bytes): a scalar, a u-coordinate or a result.
- [`FieldElement`](#type-fieldelement): a number mod p as limbs.

### Constants

- [`CRYPTO_X25519_ZERO`](#constant-crypto_x25519_zero): the status for an all-zero result.

## Spec

- Document: [RFC 7748](https://www.rfc-editor.org/rfc/rfc7748), January 2016.
- Section: 5 (the X25519 function: decodeScalar25519, decodeUCoordinate, the Montgomery ladder, a24 = 121665), 6.1 (the all-zero check).
- The zero check matches TLS 1.3 ([RFC 8446](https://www.rfc-editor.org/rfc/rfc8446) section 7.4.2), which must abort on an all-zero X25519 secret.
- A public key is X25519(a, 9): `u` holds 9, then 31 zero bytes.

## Function `crypto_x25519`

Computes X25519(k, u), the u-coordinate of k times the point with u-coordinate u.

### Signature

```
crypto_x25519(scalar, u, result) -> status
```

### Arguments

| Name | Role | Type |
|---|---|---|
| `scalar` | input | `X25519Bytes` |
| `u` | input | `X25519Bytes` |
| `result` | output | `X25519Bytes` |

### Returns

- `CRYPTO_OK`: `result` holds the u-coordinate, below p, little endian.
- `CRYPTO_X25519_ZERO`: the result is all zero bytes, which happens when u has small order. Nothing is written.

### Caller must

- Keep `result` apart from the inputs.

### Function does

- Clears bits 0, 1, 2 and 255 of the scalar and sets bit 254 (decodeScalar25519).
- Clears bit 255 of u and takes u as it is, also when it is p or more (decodeUCoordinate).
- Runs the ladder of RFC 7748 section 5 over bits 254 down to 0, with masked swaps.
- Computes x2 / z2 with z2^(p - 2), and reduces it below p.

### Function never

- Branches or picks an address based on the scalar or u.
- Writes more than `result` and its own stack.
- Keeps a pointer after it returns.
- Makes an OS call.

### Limits

- Stack: 784 bytes on x86-64 (return address included), 832 bytes on ARM64, 864 bytes on RISC-V, callees included.
- Field operations: 255 ladder steps of 5 products, 4 squarings and a product by a24, then 255 squarings and 253 products for the inverse.

### ABI

- Role: L2.
- Symbol: `crypto_x25519` (`_crypto_x25519` on macOS).
- Convention: the core ABI for each ISA (ARCHITECTURE.md section 6).
- Argument order: `scalar`, `u`, `result`.

## Function `crypto_x25519_invert`

Computes a^(p - 2), which is 1 / a mod p for a not 0 mod p, and 0 for a = 0 mod p.

### Signature

```
crypto_x25519_invert(result, a) -> nothing
```

### Arguments

| Name | Role | Type |
|---|---|---|
| `result` | output | `FieldElement` |
| `a` | input | `FieldElement` |

### Function does

- Squares, and multiplies where a bit of p - 2 is 1, from bit 254 down.
- Copies `a` first, so `result` may be `a`.

### Function never

- Branches or picks an address based on a. The exponent p - 2 is public.
- Writes more than `result` and its own stack.
- Makes an OS call.

### Limits

- Stack of its own: 128 bytes on x86-64 (return address included), 160 bytes on ARM64, 176 bytes on RISC-V.

### ABI

- Role: L0.
- Symbol: `crypto_x25519_invert`, local to its object.
- Convention: the core ABI for each ISA (ARCHITECTURE.md section 6). It returns no status.
- Argument order: `result`, `a`.

## Function `crypto_x25519_mul`

Computes a * b mod p as a number below 2^256.

### Signature

```
crypto_x25519_mul(result, a, b) -> nothing
```

### Arguments

| Name | Role | Type |
|---|---|---|
| `result` | output | `FieldElement` |
| `a` | input | `FieldElement` |
| `b` | input | `FieldElement` |

### Function does

- Computes the 512-bit product, then adds 38 times its high half to its low half, since 2^256 = 38 mod p.
- Folds the top limb back with 38 again, and a last carry with 38 once more.
- Writes `result` last, so it may be `a` or `b`.

### Function never

- Branches or picks an address based on a or b.
- Writes more than `result` and its own stack.
- Makes an OS call.

### Limits

- Stack of its own: 80 bytes on x86-64 (return address included), 64 bytes on ARM64, 64 bytes on RISC-V.

### ABI

- Role: L0.
- Symbol: `crypto_x25519_mul`, local to its object.
- Convention: the core ABI for each ISA (ARCHITECTURE.md section 6). It returns no status.
- Argument order: `result`, `a`, `b`.

## Function `crypto_x25519_cswap`

Swaps a and b when mask is all ones, and keeps them when mask is 0, with the same instructions.

### Signature

```
crypto_x25519_cswap(a, b, mask) -> nothing
```

### Arguments

| Name | Role | Type |
|---|---|---|
| `a` | state | `FieldElement` |
| `b` | state | `FieldElement` |
| `mask` | input | u64 in a register, 0 or all ones |

### Caller must

- Keep `a` apart from `b`.

### Function does

- Computes t = (a XOR b) AND mask, then a XOR t and b XOR t.

### Function never

- Branches or picks an address based on a, b or mask.
- Writes more than `a` and `b`.
- Makes an OS call.

### Limits

- Stack of its own: 8 bytes on x86-64, its return address, and none on ARM64 and RISC-V.

### ABI

- Role: L0.
- Symbol: `crypto_x25519_cswap`, local to its object.
- Convention: the core ABI for each ISA (ARCHITECTURE.md section 6). It returns no status.
- Argument order: `a`, `b`, `mask`.

## Type `X25519Bytes`

32 bytes of RFC 7748: a scalar, a u-coordinate or a result.

### Layout

| Offset | Field | Type | Meaning |
|---|---|---|---|
| 0 | `bytes` | 32 bytes | A little-endian number |

### Rules

- The buffer starts at a multiple of 8.
- A scalar holds key material.

## Type `FieldElement`

A number mod p = 2^255 - 19, as limbs.

### Layout

| Offset | Field | Type | Meaning |
|---|---|---|---|
| 8i | `limb[i]` | u64 | Bits 64i to 64i + 63 |

### Rules

- 32 bytes, at a multiple of 8.
- Any number below 2^256 that stands for its value mod p; only `crypto_x25519` reduces below p.

## Constant `CRYPTO_X25519_ZERO`

- Value: 7.
- Status of `crypto_x25519` when the result is all zero bytes.

## Test vectors

- RFC 7748 section 5.2 (the two X25519 vectors, and the iterations up to 1000, each one a case) and section 6.1 (the two public keys and the shared secret, from both sides)
  - File: [`rfc7748.txt`](https://www.rfc-editor.org/rfc/rfc7748.txt), SHA-256 `279ca0ecc5e92e2962e27b846986aeb74729d9dd34bd4a04a362f80dcb596ad3`.
- Wycheproof X25519, every case
  - File: [`x25519_test.json`](https://github.com/C2SP/wycheproof/blob/65ca494727a52944c204441c860b039e6786b99b/testvectors_v1/x25519_test.json), SHA-256 `35c3f5231cf25cc640b524d403461deee9e49441d5d915a3a25b2c8ff5adbe7d`.
  - A case with an all-zero shared value must give `CRYPTO_X25519_ZERO`.
- Generated cases
  - 200 key pairs: both public keys, and the shared secret from both sides, which must agree.
  - u of 0, 1, 2, p - 1, p, p + 1, p + 9, 2^255 - 1, 2^255, 2^255 + 9, 2^256 - 1 and 40 random values; scalars of all zeros, all ones, 1 and 2^255.
  - Expected results: `cryptography` 50.0.2 (OpenSSL), pinned with hashes in [tests/generator/requirements.txt](../../tests/generator/requirements.txt); a result it refuses as all zero is `CRYPTO_X25519_ZERO`.
