## Spec

- Document: [RFC 8032](https://www.rfc-editor.org/rfc/rfc8032), January 2017.
- Sections: 5.1 (Ed25519: p, d, B, L, the encoding 5.1.2, decoding 5.1.3, point addition 5.1.4, key generation 5.1.5, signing 5.1.6, verifying 5.1.7).
- The check of section 5.1.7 is the cofactorless one: [S]B - [k]A, encoded, must equal the 32 bytes of R. OpenSSL, Go `crypto/ed25519` and `ed25519-dalek` use the same check.
- A public key or an R whose y is p or more does not decode, and neither does x = 0 with the sign bit set (section 5.1.3, steps 1 and 4). An R that does not decode never equals a canonical encoding, so it fails the check.
- S must be below L (section 5.1.7, step 1).
- Use: libp2p peer IDs of the Ed25519 key type ([peer-ids@c750236](https://github.com/libp2p/specs/blob/c750236de43cd8b246a824b377dfdb26bae686db/peer-ids/peer-ids.md)), which every libp2p implementation must support.
- Field elements: [`FieldElement`](x25519.md#type-fieldelement) of X25519, below 2^256 and mod p = 2^255 - 19.

## Function `crypto_ed25519_public_key`

Writes the public key A = [s]B of a private key, as section 5.1.5 says.

### Signature

```
crypto_ed25519_public_key(private_key, public_key) -> status
```

### Arguments

| Name | Role | Type |
|---|---|---|
| `private_key` | input | `Ed25519PrivateKey` |
| `public_key` | output | `Ed25519PublicKey` |

### Returns

- `CRYPTO_OK`, always.

### Caller must

- Keep `public_key` apart from `private_key`.

### Function does

- Computes s with `crypto_ed25519_expand`, then [s]B with `crypto_ed25519_point_mul`, and encodes it.

### Function never

- Writes more than `public_key` and its own stack.
- Keeps a pointer after it returns.
- Makes an OS call.
- Branches or picks an address based on the private key.

### Effects

- Its stack holds key material after it returns.

### Limits

- Stack: 1424 bytes on x86-64 (return address included), 1504 bytes on ARM64, 1664 bytes on RISC-V, callees included.

### ABI

- Role: L2.
- Symbol: `crypto_ed25519_public_key` (`_crypto_ed25519_public_key` on macOS).
- Convention: the core ABI for each ISA (ARCHITECTURE.md section 6).
- Argument order: `private_key`, `public_key`.

## Function `crypto_ed25519_sign`

Signs a message with a private key, as section 5.1.6 says.

### Signature

```
crypto_ed25519_sign(private_key, message, signature) -> status
```

### Arguments

| Name | Role | Type |
|---|---|---|
| `private_key` | input | `Ed25519PrivateKey` |
| `message` | input | [`ByteList`](sha-256.md#type-bytelist) |
| `signature` | output | `Ed25519Signature` |

### Returns

- `CRYPTO_OK`, always.

### Caller must

- Pass a valid `ByteList` in `message`. It is not checked.
- Keep `signature` apart from the inputs.

### Function does

- Computes s and the prefix with `crypto_ed25519_expand`, and A = [s]B.
- Computes r = SHA-512(prefix || M) mod L and R = [r]B.
- Computes k = SHA-512(R || A || M) mod L and S = (r + k * s) mod L.
- Writes R, then S little endian.
- Computes A itself, so a wrong public key cannot leak the private key.

### Function never

- Reads more than `private_key`, the `ByteList` header and its `count` bytes.
- Writes more than `signature` and its own stack.
- Keeps a pointer after it returns.
- Makes an OS call.
- Branches or picks an address based on the private key, r or the message.

### Effects

- Its stack holds key material after it returns.

### Limits

- Stack: 1712 bytes on x86-64 (return address included), 1792 bytes on ARM64, 1952 bytes on RISC-V, callees included.

### ABI

- Role: L2.
- Symbol: `crypto_ed25519_sign` (`_crypto_ed25519_sign` on macOS).
- Convention: the core ABI for each ISA (ARCHITECTURE.md section 6).
- Argument order: `private_key`, `message`, `signature`.

## Function `crypto_ed25519_verify`

Checks a signature of a message against a public key, as section 5.1.7 says.

### Signature

```
crypto_ed25519_verify(public_key, message, signature, valid) -> status
```

### Arguments

| Name | Role | Type |
|---|---|---|
| `public_key` | input | `Ed25519PublicKey` |
| `message` | input | [`ByteList`](sha-256.md#type-bytelist) |
| `signature` | input | `Ed25519Signature` |
| `valid` | output | [`Valid`](secp256k1.md#type-valid) |

### Returns

- `CRYPTO_OK`: `valid` holds 1 or 0.
- `CRYPTO_INVALID_PUBLIC_KEY`: `public_key` does not decode to a point. Nothing is written.

### Caller must

- Pass a valid `ByteList` in `message`. It is not checked.
- Keep `valid` apart from the inputs.

### Function does

- Decodes A with `crypto_ed25519_point_decode`.
- Writes 0 when S is L or more.
- Computes k = SHA-512(R || A || M) mod L, then [S]B - [k]A.
- Writes 1 when the encoding of that point equals the 32 bytes of R, else 0.

### Function never

- Reads more than the `ByteList` header and its `count` bytes, `public_key` and `signature`.
- Writes more than `valid` and its own stack.
- Keeps a pointer after it returns.
- Makes an OS call.

### Limits

- Stack: 1840 bytes on x86-64 (return address included), 1920 bytes on ARM64, 2000 bytes on RISC-V, callees included.

### ABI

- Role: L2.
- Symbol: `crypto_ed25519_verify` (`_crypto_ed25519_verify` on macOS).
- Convention: the core ABI for each ISA (ARCHITECTURE.md section 6).
- Argument order: `public_key`, `message`, `signature`, `valid`.

## Function `crypto_ed25519_expand`

### Signature

```

```

### Arguments

| Name | Role | Type |
|---|---|---|
| `h` | output | 64 bytes: s, then the prefix |

### Function never

### Limits

- Convention: the core ABI for each ISA (ARCHITECTURE.md section 6). It returns no status.
- Argument order: `h`, `private_key`.

## Function `crypto_ed25519_scalar_reduce`

Reduces a 64-byte little-endian number mod L.

### Signature

```
crypto_ed25519_scalar_reduce(result, h) -> nothing
```

### Arguments

| Name | Role | Type |
|---|---|---|
| `result` | output | [`Number`](secp256k1.md#type-number) |
| `h` | input | 64 bytes |

### Function does

- Splits h into lo and hi, and computes lo * 2^256 + hi * 2^512 mod L with two Montgomery products and a sum.
- Removes the 2^256 with one more Montgomery product by 1, so `result` is h mod L, below L.

### Function never

- Writes more than `result` and its own stack.
- Makes an OS call.
- Branches or picks an address based on h.

### Limits

- Stack of its own: 192 bytes on x86-64 (return address included), 224 bytes on ARM64, 240 bytes on RISC-V.

### ABI

- Role: L0.
- Symbol: `crypto_ed25519_scalar_reduce`, local to its object.
- Convention: the core ABI for each ISA (ARCHITECTURE.md section 6). It returns no status.
- Argument order: `result`, `h`.

## Function `crypto_ed25519_point_decode`

Reads a point from its 32-byte encoding, as section 5.1.3 says.

### Signature

```
crypto_ed25519_point_decode(result, encoding) -> 0 or 1
```

### Arguments

| Name | Role | Type |
|---|---|---|
| `result` | output | `EdwardsPoint` |
| `encoding` | input | `Ed25519PublicKey` |

### Returns

- 0: `result` holds the point, with Z = 1 and T = x * y.
- 1: y is p or more, u / v has no square root, or x = 0 with the sign bit set. `result` is not written.

### Function does

- Computes the candidate x = u v^3 (u v^7)^((p - 5) / 8), with u = y^2 - 1 and v = d y^2 + 1.
- Multiplies x by 2^((p - 1) / 4) when v x^2 = -u, and takes p - x when the low bit of x differs from the sign bit.

### Function never

- Writes more than `result` and its own stack.
- Makes an OS call.

### Effects

- It branches on the encoding, which is public.

### Limits

- Stack of its own: 416 bytes on x86-64 (return address included), 448 bytes on ARM64, 464 bytes on RISC-V.

### ABI

- Role: L0.
- Symbol: `crypto_ed25519_point_decode`, local to its object.
- Convention: the core ABI for each ISA (ARCHITECTURE.md section 6). It returns 0 or 1, not a status code.
- Argument order: `result`, `encoding`.

## Type `Ed25519PrivateKey`

| Offset | Field | Type | Meaning |

| 0 | `seed` | 32 bytes | The private key |

### Rules

- The buffer starts at a multiple of 8.
- It holds key material.

| Offset | Field | Type | Meaning |
|---|---|---|---|
| 0 | `encoding` | 32 bytes | y, and the sign of x in the top bit of byte 31 |

| Offset | Field | Type | Meaning |

## Type `EdwardsPoint`

A point in extended coordinates: x = X / Z, y = Y / Z, x * y = T / Z.

### Layout

| Offset | Field | Type | Meaning |
