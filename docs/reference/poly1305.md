# Poly1305

## Contents

### Functions

- [`crypto_poly1305_mac`](#function-crypto_poly1305_mac): computes the Poly1305 tag of a message.
- [`crypto_poly1305_init`](#function-crypto_poly1305_init): sets up a state from a one-time key.
- [`crypto_poly1305_blocks`](#function-crypto_poly1305_blocks): absorbs bytes as 16-byte blocks.
- [`crypto_poly1305_emit`](#function-crypto_poly1305_emit): writes the tag.

### Types

- [`Poly1305Key`](#type-poly1305key): a 32-byte one-time key.
- [`Poly1305State`](#type-poly1305state): the accumulator and the key.
- [`Poly1305Tag`](#type-poly1305tag): a 16-byte tag.

## Spec

- Document: [RFC 8439](https://www.rfc-editor.org/rfc/rfc8439), June 2018.
- Section: 2.5 (Poly1305): `poly1305_mac` adds the 2^128 bit to each full block, and a 0x01 byte after a last part block.
- Section: 2.8 (the AEAD input): every block is a full 16-byte block, padded with zeros (pad16), so each block carries the 2^128 bit.
- The arithmetic works in base 2^64, as OpenSSL's `poly1305_blocks` does: h has three limbs, and each block costs five 64 x 64 products.

## Function `crypto_poly1305_mac`

Computes poly1305_mac of RFC 8439 section 2.5.1: the tag of a message under a one-time key.

### Signature

```
crypto_poly1305_mac(key, message, tag) -> status
```

### Arguments

| Name | Role | Type |
|---|---|---|
| `key` | input | `Poly1305Key` |
| `message` | input | [`ByteList`](sha-256.md#type-bytelist) |
| `tag` | output | `Poly1305Tag` |

### Returns

- `CRYPTO_OK`: `tag` holds the tag.

### Caller must

- Pass a valid `ByteList` value in `message`. It is not checked.
- Keep `tag` apart from the inputs.
- Use each key for one message.

### Function does

- Absorbs the full 16-byte blocks with the 2^128 bit, with `crypto_poly1305_blocks`.
- Gives a last part block a 0x01 byte after its bytes, then zeros, and absorbs it without the 2^128 bit.
- Writes the tag with `crypto_poly1305_emit`.

### Function never

- Reads more than the `ByteList` header and its `count` bytes, and `key`.
- Writes more than `tag` and its own stack.
- Keeps a pointer after it returns.
- Makes an OS call.
- Branches or picks an address based on key or data bytes.

### Limits

- Stack: 208 bytes on x86-64 (return address included), 176 bytes on ARM64, 208 bytes on RISC-V, callees included.

### ABI

- Role: L2.
- Symbol: `crypto_poly1305_mac` (`_crypto_poly1305_mac` on macOS).
- Convention: the core ABI for each ISA (ARCHITECTURE.md section 6).
- Argument order: `key`, `message`, `tag`.

## Function `crypto_poly1305_init`

Sets h to 0, r to the clamped first half of the key, and s to the second half.

### Signature

```
crypto_poly1305_init(state, key) -> nothing
```

### Arguments

| Name | Role | Type |
|---|---|---|
| `state` | output | `Poly1305State` |
| `key` | input | `Poly1305Key` |

### Caller must

- Keep `state` apart from `key`.

### Function does

- Clamps r as RFC 8439 section 2.5 says: r0 AND 0x0FFFFFFC0FFFFFFF, r1 AND 0x0FFFFFFC0FFFFFFC, as little-endian limbs.
- Stores s1 = r1 + r1 / 4, which is 5 * r1 / 4 since the clamp clears the low 2 bits of r1.

### Function never

- Writes more than `state`.
- Makes an OS call.

### Limits

- Stack of its own: 8 bytes on x86-64, its return address, and none on ARM64 and RISC-V.

### ABI

- Role: L0.
- Symbol: `crypto_poly1305_init`, local to its object.
- Convention: the core ABI for each ISA (ARCHITECTURE.md section 6). It returns no status.
- Argument order: `state`, `key`.

## Function `crypto_poly1305_blocks`

Absorbs count bytes into the accumulator, as 16-byte blocks padded with zeros.

### Signature

```
crypto_poly1305_blocks(state, data, count, pad) -> nothing
```

### Arguments

| Name | Role | Type |
|---|---|---|
| `state` | state | `Poly1305State` |
| `data` | input | `count` bytes |
| `count` | input | u64 in a register |
| `pad` | input | u64 in a register, 0 or 1 |

### Caller must

- Pass a state from `crypto_poly1305_init` or from this function.
- Start `data` at a multiple of 8.

### Function does

- For each block m: h = (h + m + pad * 2^128) * r, partly reduced mod 2^130 - 5.
- Pads the last block with zeros to 16 bytes when `count` is not a multiple of 16.
- Keeps h2 below 2^3 between blocks.

### Function never

- Branches or picks an address based on key or data bytes.
- Writes more than `state` and its own stack.
- Makes an OS call.

### Limits

- Stack of its own: 80 bytes on x86-64 (return address included), 16 bytes on ARM64, 32 bytes on RISC-V.

### ABI

- Role: L0.
- Symbol: `crypto_poly1305_blocks`, local to its object.
- Convention: the core ABI for each ISA (ARCHITECTURE.md section 6). It returns no status.
- Argument order: `state`, `data`, `count`.

## Function `crypto_poly1305_emit`

Writes the tag: h fully reduced mod 2^130 - 5, plus s, mod 2^128.

### Signature

```
crypto_poly1305_emit(state, tag) -> nothing
```

### Arguments

| Name | Role | Type |
|---|---|---|
| `state` | input | `Poly1305State` |
| `tag` | output | `Poly1305Tag` |

### Caller must

- Keep `tag` apart from `state`.
- Start `tag` at a multiple of 8.

### Function does

- Computes g = h + 5 and takes g mod 2^128 when g reaches 2^130, through a mask, else h.
- Adds s and writes the low 128 bits, little endian.

### Function never

- Branches or picks an address based on the state.
- Writes more than `tag`.
- Makes an OS call.

### Limits

- Stack of its own: 8 bytes on x86-64, its return address, and none on ARM64 and RISC-V.

### ABI

- Role: L0.
- Symbol: `crypto_poly1305_emit`, local to its object.
- Convention: the core ABI for each ISA (ARCHITECTURE.md section 6). It returns no status.
- Argument order: `state`, `tag`.

## Type `Poly1305Key`

A one-time key: r, then s.

### Layout

| Offset | Field | Type | Meaning |
|---|---|---|---|
| 0 | `r` | 16 bytes | A little-endian number, clamped before use |
| 16 | `s` | 16 bytes | A little-endian number |

### Rules

- 32 bytes, at a multiple of 8.
- It holds key material.

## Type `Poly1305State`

The accumulator h and the key.

### Layout

| Offset | Field | Type | Meaning |
|---|---|---|---|
| 0 | `h0` | u64 | Bits 0 to 63 of h |
| 8 | `h1` | u64 | Bits 64 to 127 of h |
| 16 | `h2` | u64 | Bits 128 and up of h, below 2^3 between blocks |
| 24 | `r0` | u64 | The clamped r, low limb |
| 32 | `r1` | u64 | The clamped r, high limb |
| 40 | `s1` | u64 | r1 + r1 / 4 |
| 48 | `s` | 16 bytes | s, little endian |

### Rules

- 64 bytes, at a multiple of 8. `CRYPTO_POLY1305_STATE_SIZE` in [include/chacha20.inc](../../include/chacha20.inc).
- It holds key material. It lives on the stack of the calling function.

## Type `Poly1305Tag`

A Poly1305 tag.

### Layout

| Offset | Field | Type | Meaning |
|---|---|---|---|
| 0 | `tag` | 16 bytes | A little-endian number |

### Rules

- The buffer starts at a multiple of 8.
